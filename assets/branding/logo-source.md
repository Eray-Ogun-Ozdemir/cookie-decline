# Cookie Decline logo

- Source: the user-supplied PNG selected as the project logo.
- Design: a chocolate-chip cookie being cut by scissors with red handles.
- Master asset: `public/icons/cookie-decline-logo.png`, 534 × 534 PNG with transparency.
- The master is an unchanged copy of the supplied image.
- Chrome exports: `public/icons/icon-16.png`, `icon-32.png`, `icon-48.png`, and `icon-128.png`.
- The Chrome exports are resized copies that preserve transparency.

The extension manifest, popup, README, and demo reference these assets.
